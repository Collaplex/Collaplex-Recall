## 与流程图不一致、但属于有意决策

1. **一次性渲染替代流式输出**：用户要求不展示思考、等完成再整段渲染。
2. **检索是固定阶段，不是模型发起的工具调用**：当前 TUI 每次提问自动检索一次，没有 tool calling；只读不受影响，但“模型自主决定搜不搜”还没做到。
3. **RRF 换成了两段式重排**：向量召回候选，候选内 BM25 重排（α=0.05）；实测 RRF 会明显掉分。
4. **不画记忆图**：用户明确表示不需要图形化，TUI 里用 `/why` 代替。
