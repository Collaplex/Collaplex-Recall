# 笔记软件架构

## 三层存储

笔记库是原文，唯一事实源，只有人能写，用 git 管版本。记忆库是派生结论，由模型异步写 delta，可以审、可以删。二层表是工作集，一轮就过期，必须落盘 JSONL 才能复现。

## 模型权限

模型对笔记库永远只读。工具白名单只有 search、read、propose，结构上不存在写原语。笔记的每一次修改都由人执行，模型只能出 diff 提案。

## 每轮重建上下文

不做滑动窗口，也不做摘要压缩。每轮提问都从零重建上下文：判题改写、别名展开、记忆检索、search 工具、组装、生成带引用。上下文是每轮算出来的视图，不是不断增长的日志。

## 检索

检索是一个工具，不是流程阶段。模型只看到 search 返回的十条结果，永远看不到一百条候选。笔记侧用向量加 BM25 混合召回，再交给交叉编码器精排。要调的是打分系数，不是模型参数。

## 明确不做

不微调模型存事实，权重不可删。不让生成模型直接排一百条，位置偏置太严重。不让模型写笔记，一旦允许就要处理冲突、并发和回滚。
